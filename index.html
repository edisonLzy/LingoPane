Apple HIG 交互规范注解
1. 悬浮面板设计哲学

遵循 macOS Utility Panel (NSPanel) 规范。不抢占当前活动应用的焦点，首屏只呈现翻译结果。宽度统一为 410px，最大高度 520px，内容过长时使用原生 macOS 叠加滚动条。

2. 句子成分可视化映射规范 (PRD §7)
主语 (Subject) 蓝色实线下划线
谓语 (Predicate) 橙色实线下划线
宾语 (Object) 绿色实线下划线
补语 (Complement) 紫色实线下划线
状语 (Adverbial) 灰色虚线下划线
定语从句 蓝色半透明圆角方框
条件从句 橙色半透明方框
让步从句 红色半透明方框
3. 交互微动效与固定机制
  • Hover 延迟：悬停 250ms 后轻量浮出说明气泡，避免快速扫视产生视觉闪烁。
  • 点击固定 (Pin)：触控板轻按即可 Pin 住说明卡片，用户可自由选择复制卡片内文字。
  • Esc 快捷关闭：按下 Esc 或点击外部区域立即解除固定。
  • 降级容错：若语法结构校验失败，降级展示纯翻译，绝不让用户面临空白错误。
4. 原生 Swift 技术落地指引
• 浮窗：NSPanel(styleMask: [.nonactivatingPanel, .fullSizeContentView])
• 材质：NSVisualEffectView(material: .popover, blendingMode: .behindWindow)
• 选中取词：AXUIElementCopyAttributeValue(systemWide, kAXFocusedUIElementAttribute)
• 降级兜底：模拟 CGEvent(keyboardEventSource) ⌘C
• 语法高亮：NSTextView + NSAttributedString Range
